# Guía de Instalación

Sigue estos pasos para clonar el repositorio e iniciar el servidor de desarrollo local.

### 1. Clonar el repositorio
Ejecuta el siguiente comando en tu terminal para descargar el código fuente:

```bash
git clone [https://codeberg.org/tu_usuario/weather-app-js.git](https://codeberg.org/tu_usuario/weather-app-js.git)
cd weather-app-js
